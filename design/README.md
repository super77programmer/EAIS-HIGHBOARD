# School workspace visual direction

Editable Figma file: https://www.figma.com/design/reo7vMDacUfLmRnZOG1UK8

Screens:
- Student home · Desktop — node 2:322
- Calendar · Desktop — node 2:323
- Trip details · Mobile — node 2:324

These are editable design concepts with example content, not screenshots of live student records or a pixel-identical export of the app. Buttons reuse Material 3 components; the event summary uses an editable card slot. Layouts use auto-layout frames and editable text, with DM Sans and Manrope retained from the app. School accent: #2457a7; ink: #192b43; muted text: #586b80; borders: #dce4ec; canvas: #f5f7fa. Concepts were checked using Figma screenshots and corrected for text reflow, nested button styling and frame height. The last minor slot-text/button-label correction was structurally confirmed; a further screenshot was blocked by the Starter-plan tool-call limit.

The production update applies the visual direction to the app shell and existing pages, preserves the school branding, adds grouped navigation and a mobile drawer, removes the opening delay, and adds real calendar search/category filters. Figma does not hold account data, chat messages or trip interest records.
